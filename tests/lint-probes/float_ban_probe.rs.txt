// GENERATED probe — a .txt file so cargo never compiles it during a normal build.
// tests/lints.sh copies it to tests/_probe.rs, runs clippy, and asserts that the
// number of `use of a disallowed method` diagnostics equals the number of marked call
// sites below. Clippy accepts an unresolvable disallowed-methods path in silence,
// so without this comparison a typo in clippy.toml is indistinguishable from a
// working ban. Every entry that resolves on the pinned stable toolchain is called
// exactly once, on BOTH float widths. Each marked call site is a line whose final
// token is the marker; the marker deliberately appears nowhere else in this file, so
// counting it is exact rather than approximately right.
//
// Excluded, and only these: erf, erfc, gamma, ln_gamma — unstable in std, so they cannot be
// called on stable at all. Their clippy.toml entries stay; the exclusion is the
// documented hole, and it is documented rather than silent.

// ---- the clock, banned for the same reason as the floats ----
// These two are not float methods, but they are disallowed-methods entries in
// the same list and the same silence applies: clippy ignores a path it cannot
// resolve without any diagnostic. Before these lines the count comparison in
// tests/lints.sh check 3 covered the 58 callable float bans and ZERO clock
// bans, so `std::time::SystemTime::now` and `std::time::Instant::now` were the
// only entries in clippy.toml whose resolution nothing asserted -- and the
// wall-clock ban is one of the top determinism hazards in CLAUDE.md.
pub fn probe_systemtime_now() -> std::time::SystemTime { std::time::SystemTime::now() } // BANNEDCALL
pub fn probe_instant_now() -> std::time::Instant { std::time::Instant::now() } // BANNEDCALL
