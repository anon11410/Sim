<objective>
Ship the provenance machinery CORE-11 requires: every config value carries its source grade, and
the values inherited from an annotated replication rather than read from the published paper are
marked as such, above a procedure a person can execute to close the gap.

Purpose: `01-RESEARCH.md` recorded that primary-source access is egress-blocked on all six
candidate hosts, and that this is the second independent research pass to hit the same wall. Every
value in the repository attributed to the baseline-model paper is therefore inherited, and none has
been read from a primary source. CONTEXT.md D-19 moves the verification itself to a blocking gate
on Phase 6 — the first phase that consumes those values — because no phase before then uses them,
so blocking the project's first phase on an out-of-band human action buys no risk reduction. What
Phase 1 owes is the machinery and the honest marking, and this plan delivers both.

The failure this exists to prevent is specific: an agent transcribing a parameter table from
training memory and quietly marking it verified. That produces a number that looks sourced, is not,
and drives the widest-sensitivity region of the model.

Output: `config/PROVENANCE.md`, `config/baseline.toml` annotated key by key, and
`tests/provenance.rs` converting the annotation requirement from a review item into an automated
gate.
</objective>
