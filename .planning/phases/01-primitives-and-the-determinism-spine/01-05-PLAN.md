<objective>
Build the two remaining primitive modules: identity that cannot silently alias across a respawn,
and a float domain small enough to hold in one hand.

Purpose on identity: Phase 10 destroys and replaces firms in place. Without a generation on the
identity, a `FirmId` captured before a bankruptcy resolves after the respawn to a *different*
firm, and the resulting bug is a wrong number rather than a crash — the hardest class to find in
an emergent system. The generation turns it into a typed miss.

Purpose on the float domain: MKT-01's consumption rule needs `(m / P_bar)^0.9`, which needs the
floating-point power function, which is on the list CORE-07 requires this phase to ban — and
which the standard library documents as varying *within a single execution*. `01-RESEARCH.md`
verified the resolution: the same value computed by binary expansion of the exponent using only
the square root and multiplication is accurate to about two parts in a trillion and bit-identical
across a hundred thousand invocations. Shipping it now is what keeps the ban honest, so that
Phase 7 never has to weaken it under deadline. CONTEXT.md D-12 flags this explicitly as a Phase 7
concern deliberately landing in a Phase 1 plan.

Output: `src/ids.rs`, `src/numeric.rs`, their test files, and `src/lib.rs` extended to declare
both.
</objective>
