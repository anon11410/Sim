<objective>
Build the wall that makes every other determinism rule in this phase real: a clippy configuration
that fails the build on a nondeterministic construct, a negative test proving it fires, and a CI
job that runs it with the flags that actually lint every target.

Purpose: `01-RESEARCH.md` found three enforcement holes in the inherited plan, each of which would
have shipped as a silently-passing gate. Plain `cargo clippy` does not lint the test directory —
verified, exit 0 with a hashed map sitting in a test file. Clippy silently ignores a
disallowed-method path it cannot resolve, so a typo in one of sixty-six float paths is accepted
without a diagnostic. And a type alias behind a lint exemption makes every downstream use of that
alias invisible. This plan closes all three, and follows the standard the project applies to its
own invariants: a lint never observed to block has never been shown to work.

Output: `clippy.toml` generated rather than typed, `tests/lints.sh` as the negative test, two
non-compiled probe sources, and a CI workflow.
</objective>
