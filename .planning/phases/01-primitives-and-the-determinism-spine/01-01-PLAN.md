<objective>
Stand up the whole Phase 1 spine as one thin, production-quality path that runs end to end:
a TOML config is read from disk, hashed over its raw bytes, parsed into a typed `Params`
tree; the effective seed is resolved from `--seed` or the config; one RNG sub-stream is
opened and one draw taken; one `Money` value is constructed and added. The binary prints a
single deterministic line, and an integration test proves the same seed reproduces it and a
different seed does not.

Purpose: prove the architecture CLAUDE.md and `01-RESEARCH.md` specify actually composes —
before six sibling plans build out `Money`, the RNG facade, identity, the float domain, the
lint wall and the config schema on top of it. Every later plan in this phase widens one of
the layers this task wires; none of them changes its shape.

Output: a compiling, testable single crate (`lib.rs` + thin `main.rs`, CORE-08), a pinned
and committed toolchain and lockfile (CORE-09), and a release profile that cannot silently
wrap (CORE-02).
</objective>
