    - `Money::from_cents(1000).split(3)` returns exactly `[334, 333, 333]` in cents — the first `1000 % 3 == 1` recipient gets the extra cent, by ascending index.
    - `Money::from_cents(1000).split(4)` returns `[250, 250, 250, 250]` — no remainder, no extra cent anywhere.
    - `Money::from_cents(2).split(5)` returns `[1, 1, 0, 0, 0]` — the remainder rule holds when the amount is smaller than the recipient count.

    - `Money::ZERO.split(4)` returns four zeros.
    - `Money::from_cents(-1000).split(3)` returns parts that sum exactly to `-1000` — negative amounts are representable because intermediate deltas and residuals can be negative.
    - `Money::from_cents(1000).split(0)` panics with a message naming the zero recipient count.
    - Two consecutive calls to `Money::from_cents(1000).split(3)` return equal vectors.

    `src/money.rs` first, watch them fail, then implement.
