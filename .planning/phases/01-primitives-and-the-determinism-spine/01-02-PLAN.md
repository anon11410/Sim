factual error in the project's technology contract that produced one of them.

small-RNG type is unconditional in `rand` 0.10 — only the standard-RNG type is feature-gated.

count into an economics config where someone would eventually tune it — and tuning it silently
changes every trajectory.

this phase, in plan `01-08`. Its paper-verification clause cannot: primary-source access was
egress-blocked on all six candidate hosts across two independent research passes, and per D-19

that deferral is recorded only in CONTEXT.md, so `REQUIREMENTS.md` and Phase 1 Success Criterion
5 still grade this phase against a clause no plan in it delivers. That is precisely the failure
this plan's own prohibition names — a gate that quietly moved. Task 4 moves it visibly instead.

rationale in the same diff. That is the difference between an auditable restatement and a quiet
loosening. Per D-17, D-18 and D-19 the user delegated these explicitly.
