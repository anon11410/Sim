       the divergence localiser, and its constancy is itself an assertion worth making — a tick

       what that column proves; it does not delete the column, and a reader who takes the
       correction as "remove the draw count" would remove a diagnostic.
    2. **The scope of the claim.** At this phase `events.jsonl` carries only the opening
       endowment, which is seed-independent, so the counter-check is asserted on `ticks.csv`
       specifically. State it. The superseded phrasing promised that *all* logs differ, which
       would be a red build for a correct simulation, and the criterion must not keep a promise
       the phase deliberately does not make. The phrase `seeds produce different logs` must not
       survive anywhere in criterion 3 — one of this task's checks asserts its absence from that
       line, precisely because the phrase is the defect.
    3. **The standing check it hands forward.** Any determinism column whose distinct-value
       count over a run is 1 is a constant column and proves nothing about the seed; Phase 4's
       harness should assert the digest column has more than one distinct value.

    Then append, inside the same numbered item, a trailing italic amendment parenthetical in the
    shape Phase 2 criterion 2 already uses. It must carry, in this order: that the mechanism
    clause was amended on 2026-08-31; the authority (`03-RESEARCH.md` Pitfall 1, restated in

    built exactly as the criterion first read and run at seeds 42 and 43 over 3,650 ticks,
