<objective>
Turn every determinism claim this phase makes into a test that has been shown to be capable of
failing.

Purpose: an economics-free phase can prove nothing by behaving sensibly. Every criterion here is
a claim about bytes on disk and about a test that would be red if the claim were false — and the
research measured that the obvious spellings of three of these tests pass while certifying
nothing. Two empty files hash equal. A hand-written list of diffed files silently stops covering
a file the run later adds. An excluded file that was never written excludes nothing. Each of
those is closed by an explicit clause here rather than by care.

This plan also delivers the process-level half of Phase 2's halt claim. Phase 2 could prove only
that a tick loop aborts at the right tick, because the phase table and the binary's tick loop are
this phase's; ROADMAP Phase 3 criterion 6 records the process level against this phase precisely
so it cannot fall between the two.

Output: one test file carrying nine tests across three claims — reproducibility, the enforced
exclusion, and the halt.

    Add the process-level halt test to the same file, under the phase validation map's name.

    Build the overridden configuration by **textual substitution over the shipped file**, in a
    temporary directory. Read the shipped configuration, count the occurrences of the liveness
    leaf in its off state, and **assert that count is exactly one** before substituting. That
    assertion is the point of the exercise: without it, a reworded configuration would silently
    produce a file with the gate still off, the binary would complete 3,650 ticks, the test would
    pass — and it would be passing as a second copy of criterion 1 while claiming to prove
    criterion 6.

    The project forbids environment-variable configuration overrides as an invisible input: an
    input that is neither in the committed configuration nor in the run's record makes the run
    irreproducible from the repository. So the override is a file the test writes, and the binary
    reads it exactly as it reads any other configuration.

    Do **not** build the file by re-serialising the parsed parameters. That works, but it strips
    every comment, and the comments carry the source grades that the provenance tests make
    load-bearing. Textual substitution is the honest one-leaf override.

    Then invoke the built binary against that file, into a temporary output directory, and assert:

    - it **fails**, with exit code one;
    - the captured standard error names tick 0;
    - the captured standard error names the check that fired;
    - the captured standard error does **not** contain the temporary directory's path. That is
      TICK-06 at the message level and the runtime half of the source guard that covers the
      modules rendering the message; neither half is sufficient alone;
    - the run record was still written, and records zero ticks completed and a violation outcome —
      so a halted run is self-describing;
    - the tick file exists and is header-only, which is what the eager header buys: a halted run
      leaves an openable file rather than a zero-byte one.

    Add a comment recording why tick 0 and not a later tick: the ledger clears the endowment
    postings at construction, so tick 0's journal is empty and the liveness check fires on the
    first tick. The endowment cannot satisfy it. That is Phase 2's construction doing the work,
    and it is why this criterion needs no fault injection at all — the liveness violation is the
    one violation reachable through the public ledger API.
  </action>
