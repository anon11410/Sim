<objective>
The tracer: one run from the configuration file, through the world, the fixed nine-phase tick
pipeline and the invariant check, into a `ticks.csv` on disk that a different seed changes.

Purpose: this is the thinnest path that touches every layer this phase will modify, wired end
to end and carrying a real end-to-end verification. If the pipeline shape is wrong — if the
phase table cannot return a `Result`, if the sink cannot be flushed before the process exits, if
nothing the seed touches reaches a diffed byte — this is where it is found, on one commit,
rather than after five layers have been built on top of it. Every subsequent plan in the phase
expands outward from this slice: 03-03 adds the event and provenance streams and the run record,
03-04 the schema, 03-05 the determinism suite, 03-06 the golden run.

This is a tracer, not a prototype. Every line of it is production code that ships. The nine
phase functions are no-ops **because the phase has no economics by design**, not because they
are stubs — CONTEXT.md locks that: this phase builds the table with all nine phases present.
Phases 5 to 10 replace a `noop` with a real function and change nothing else about the shape.

Output: `src/world.rs`, `src/phases.rs`, `src/log.rs`, a rewritten `src/main.rs`, guard
`7f-agents`, and a decade of empty ticks on disk.
</objective>
